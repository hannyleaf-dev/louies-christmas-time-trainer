# Louie's Christmas-tell-the-time-trainer 🎄⏰

A friendly, gamified website that helps a 4-year-old learn to tell the time on an analogue clock.

- **Learning path:** o'clock → half past → his own daily routine (bedtime, breakfast, bath…)
- **Games:** Play with the clock · What time is it? · Make the time · Louie's day · Sticker book
- **Rewards:** "GOAL!" celebrations, stars, stickers, trophies and a daily 10-star goal
- **Voice:** every instruction is spoken. A parent can record their own voice in the Grown-ups' corner, and the computer voice fills any gaps
- **Christmas theme:** snowy night sky, neon fairy lights and a "sleeps to Christmas" countdown

## Play it

Open `index.html` in Google Chrome. No install, server or account needed.

Grown-ups' corner: press and hold **🔒 Grown-ups** (top right) for 3 seconds.

## Files

| File | What it does |
|---|---|
| `index.html` | The page |
| `css/style.css` | All styling (the Christmas neon theme is the block at the end) |
| `js/core.js` | Saved progress, sound effects, voice and recording, phrase list |
| `js/xmas.js` | Night sky, snow, fairy lights, countdown |
| `js/clock.js` | The interactive clock |
| `js/mascots.js` | The three buddies |
| `js/screens.js` | Games, rewards, top bar |
| `js/parent.js` | Grown-ups' corner |
| `PRD.md` | Product requirements |

Progress and voice recordings are stored only in the browser on the device. Nothing is uploaded.
